# Custodian-Android
A modern Android application for community protection, family safety, cultural preservation, and trusted communication.


## Build

Custodian is an Android app focused on family safety, community stories, cultural knowledge, and trusted communication. Safety data is stored locally on the device.

The GitHub Actions workflow runs unit tests and builds both debug and release APKs. The release APK is currently unsigned; production signing should use a protected keystore and GitHub Actions secrets before distribution.
